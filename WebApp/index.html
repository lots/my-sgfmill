The app could not start

This page has to be served over HTTP. Opening index.html straight from disk cannot work: browsers refuse to load JavaScript modules from file:// URLs.

Easiest fix: double-click run_web_app.cmd, in this folder. It serves the app and opens your browser at the right address.

Or serve it yourself —

cd WebApp
python -m http.server 8000
# then open http://localhost:8000/

If it is being served, check that .js files are served as text/javascript, and that the browser console shows no error.
